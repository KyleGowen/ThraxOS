# Release-art research for full-screen backgrounds

Use this reference only after the song's canonical artist, title, subtitle/version, and exact simfile are known.

## Discover narrowly, verify independently

Start with one focused image query:

`<artist> <title> <version or subtitle if present> single cover album cover`

An image-search thumbnail is a lead, not evidence. Same-name releases, compilations, fan uploads, and remix artwork are common. Open a trustworthy page and confirm that its artist, release title, and version qualifier agree with the simfile.

Preferred verification sources:

1. official artist or label release page;
2. Bandcamp release page;
3. Discogs release entry with matching artist/title/version;
4. Apple Music or Spotify release page;
5. MusicBrainz release plus Cover Art Archive.

Do not treat a search-engine caption, Pinterest-style mirror, wallpaper site, or anonymous image host as proof. Reject watermarked references and artwork whose identity cannot be corroborated.

## Capture minimal evidence

Save no more than two useful images in task-owned staging outside `C:\Games\ITGmania\Songs`. For each one record:

- source page URL;
- claimed artist, title, release, and version;
- decoded pixel dimensions;
- SHA-256;
- which high-level visual traits are relevant.

Use the reference only for palette, period, typography category, texture, materials, motifs, lighting, and compositional rhythm. Do not copy the sleeve layout, logo, label name, catalog number, watermark, identifiable person, or unique illustration.

## Translate a cover into a background

A square or portrait cover is not a full-screen composition. Reinterpret its visual language across a native 16:9 canvas:

- extend atmosphere and materials naturally across the width;
- keep the focal point away from receptor and note-reading zones when practical;
- preserve readable foreground/background separation;
- avoid fake borders, album mockups, framed covers, pillarboxes, and repeated tiled art;
- use only canonical simfile text if text is intentionally included;
- prefer a fresh composition that evokes the release over a widened copy of the cover.

If the reference itself triggers input moderation, preserve the failed-attempt fact. A single remaining attempt may use only verified, non-sensitive verbal traits without attaching the image. Never paraphrase toward prohibited content or attempt safeguard evasion.
